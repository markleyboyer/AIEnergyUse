# AI energy in everyday terms

An attempt to quantify the energy used by AI, from a single chat query to a full day of Claude Code, by comparing it with household appliances and driving a car.

Live page: https://markleyboyer.github.io/AIEnergyUse/

The page is one static file (`index.html`) with the data inline. Method, caveats and sources are in the section at the bottom of the page. The Claude Code figures are third-party estimates, because Anthropic has not published energy data for Claude.
